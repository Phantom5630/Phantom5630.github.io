MY CONTRIBUTIONS

Gameplay

Gameplay Preview

  • All actions available in the game:
    • Tap and hold to block.
    • Swipe up for a parry attemp.
    • Swipe horizontally to dodge (max 2 times in a row in same direction).
    • Tap on skill button and swipe according to prompt to cast skills.
    • Tap to attack (only when monster is downed).

Player Skills

Skill Attemps

Skills Inputs setups

  • Skill successfully casted when all required swipes are performed.
  • Player will has to recast from beginning if interrupted (wrong input or is hit).
  • Able to set any combinations of swipes in 8 directions.
  • Number of inputs limited to match provided animations.

Non Programmer Friendly Setups

Setups for Dodges

Attack Randomizer

  • Dodges animations are referenced to get animation length.
